BEYOND THE SIGNAL - APP STARTER

Dieses Projekt ergänzt den vorhandenen HTML-Canvas-Prototyp um eine Capacitor-Grundstruktur für Android und iOS.

VORAUSSETZUNGEN
- Node.js 22 oder neuer
- Android: Android Studio und Android SDK
- iOS: macOS und Xcode

ANDROID UNTER WINDOWS
1. Node.js 22+ und Android Studio installieren.
2. Repository klonen.
3. App-Android-Vorbereiten.bat ausführen.
4. Das Android-Projekt in Android Studio öffnen und auf Emulator oder Testgerät starten.

IOS
iOS-Builds benötigen einen Mac mit Xcode. Im Projektordner:
npm install
npm run cap:sync
npx cap add ios
npx cap open ios

HINWEISE
- Supabase-Zugangsdaten sind absichtlich leer. Für Online-Funktionen eigenes Projekt konfigurieren.
- Werbung, Zahlungen und In-App-Käufe sind nicht implementiert.
- Vor einer Veröffentlichung Datenschutz-, Alters- und Store-Vorgaben prüfen.
